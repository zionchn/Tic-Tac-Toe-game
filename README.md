# Welcome to My Tic-Tac-Toe Game

<p>I built a tic-tac-toe game with a clean UI and functionality. It has 3 difficulty levels:</p>
<ol>
<li>Easy</li>
<li>Medium</li>
<li>Impossible</li>
</ol>

### How to Run:

<ol>
<li>Clone the repo</li>
<li>Open the project folder in any IDE like VS Code, Cursor...</li>
<li>Install requirements.txt (pip install -r requirements.txt). It contains all packages you would need</li>
<li>Run app.py, and it should open locally on port 5001</li>
</ol>
